# Kim Bowles Portfolio

## Requirements

- Node.js 20.19+, 22.13+, or 24+
- npm

## Local development

```sh
npm ci
npm run dev
```

## Quality checks and production build

```sh
npm run lint
npm run build
npm run preview
```

Vite writes the production-ready static site to `dist/`. Deploy the contents of that directory to a static host such as GitHub Pages, Netlify, or Vercel. The source repository should not include `dist/` or `node_modules/`.

The contact form opens the visitor's email app and addresses a message to `silverspace@gmail.com`.
